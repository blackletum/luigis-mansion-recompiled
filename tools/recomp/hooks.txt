# Recompiled functions that check for a host replacement (registered with HLE(name))
# before running their translated body. One symbol name per line, as named in the US
# (GLME01) symbol map, optionally followed by the versions it applies to:
#   <symbol>          US build only (default: hooks are written against US code)
#   <symbol> us pal   also the PAL build, once the hook has been checked against PAL code
#   <symbol> pal      PAL build only
#   palfn_<addr>      a function only the PAL build has (by its PAL address), tagged `pal`
# After tagging a hook `pal`, run tools/recomp/gen_version_map.py (maps it to its PAL
# address). A hook tagged `pal` runs on the European game too: its handler must use VA()/VOFF()
# for addresses and offsets (src/recomp/version.h). See docs/SETUP.md.
