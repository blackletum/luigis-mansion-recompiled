# Luigi's Mansion PC Port — working notes

## Goals
- Native PC port of Luigi's Mansion (GameCube), in the style of Dusklight (TP port), on the Aurora engine (`extern/aurora`, WebGPU/Dawn + SDL3).
- Base: USA disc **GLME01 rev 0**. Bring in the **PAL (GLMP01) Hidden Mansion** features, including its boss mechanics (Chauncey patterns, Boolossus vacuum-riding, harder Bowser), not just stat/data changes (docs/HIDDEN_MANSION.md). It is an *additional* runtime-selectable variant: E. Gadd's lab menu will offer both "Hidden Mansion (USA)" and "Hidden Mansion (PAL)" once unlocked (menu UI later).
- Enhancements: high frame rate via interpolation (logic stays 30 Hz), arbitrary resolution, widescreen + ultrawide, faithful advanced effects (EFB copies, fog, lighting, indirect).
- Every user-facing option lives in the F1 overlay menu (Esc closes): tabs Visuals / Sound / Controls (ports, bindings, sticks/rumble: `src/recomp/controls.cpp`, docs/CONTROLS.md) / Enhancements; Enhancements has sub-tabs General / Gameplay (difficulty, cheats) / Unused content (every restored unused/beta feature; all OFF by default, retail unchanged) / Debug (debug menus, warps, viewers). Add new options to `src/port/settings.h` (persisted to %APPDATA%\Luigi's Mansion PC\settings.ini) and `src/recomp/menu.cpp`; CLI flags only override for testing.

## Rendering principle
- Sister project: Super Mario Sunshine port (`C:\Users\rmelv\Desktop\Mario Sunshine PC Port`) shares the recompiler/runtime/Aurora patches. Generic GX accuracy fixes made for SMS (copy filters + box filter on GXCopyTex, 6-bit EFB alpha blending, EFB peeks/draw sync, pixel counters, copy-to-RAM formats, DSP microcode details) get backported here (and vice versa) when LM uses the feature; SMS logs them in its docs/BACKPORT.md. Keep the shared Aurora patches in sync.
- Aim for hardware-accurate GX rendering wherever possible (EFB copies incl. copy-to-RAM, TEV/indirect precision, Z textures, fog, copy filters/gamma), then make every enhancement (resolution, aspect ratio, frame rate) scale on top of the accurate base. Accept a moderate performance cost for accuracy (it's a PC port), but keep it reasonable: prefer targeted accuracy (only the copies/effects the game needs) over brute-force emulation, and measure.
- Every accuracy feature with a real cost gets a toggle in F1 > Visuals > Rendering (sub-tab), ON by default (best quality), so weaker PCs can turn it off for speed (e.g. EFB copy to RAM, Z textures, accurate copy filters). Note each toggle's visible effect in its tooltip.

## Release requirements
- Distribution: ship the recompiler + a bundled clang/lld. `LuigisMansionRecomp.exe` first run asks for US and/or PAL disc images (ISO/RVZ), then does a one-time setup (recompile DOL into a game module, build PAL overlay) into AppData (docs/SETUP.md). Features needing a disc that wasn't provided are greyed out in the F1 menu until it is added.
- End users never run scripts: the game takes their own disc images (ISO/RVZ via Aurora/nod), US and/or PAL (either alone is playable; with both the user picks the base). Anything derived from them (PAL Hidden Mansion overlay now built by tools/hidden_mansion_data.py, recompiled code) is produced automatically on the user's machine (first launch / setup), cached outside the install, and re-validated by hash.

## Architecture (see docs/RECOMPILER.md, docs/SETUP.md)
- `src/recompiler/recompiler.cpp` (C++): DOL + `decomp/config/<ver>/symbols.txt` (+ GLME01 splits / `tools/recomp/GLMP01_map.txt` for PAL) → one `void f_XXXXXXXX(Ctx&)` per function (gotos, jump-table switches, interior/address-taken entry points), 32 files. Used by `lmrecompile` at build time (target `lmrecomp`, cache vars `LM_DOL`, `LM_DOL_VERSION`) and in-process by `LuigisMansionRecomp.exe` setup.
- `LuigisMansionRecomp.exe` (what users run): setup screen picks US/PAL discs, recompiles + compiles the game module DLL with bundled clang/lld into %APPDATA%\Luigi's Mansion PC\game\<id>, builds the PAL HM overlay, then runs. Module boundary: `recomp/module_abi.h` (RuntimeApi), `module_rt.cpp`; `ctx.h` must stay freestanding (builtins only, no system headers). Bump `kModuleAbiVersion` when Ctx/GameModule/RuntimeApi change.
- PAL base: SDK/hook names come from `tools/recomp/GLMP01_map.txt` (`gen_version_map.py`). hooks.txt entries are US-only unless tagged `us pal`/`pal` (PAL-only functions: `palfn_<addr>`). Host code uses USA addresses wrapped in `VA()` and `VOFF(us, pal)` for offsets (`src/recomp/version.h`; table `version_addrs.inc` generated by `gen_version_map.py`, re-run after adding one); code still on raw US addresses must check `port::usCodeFeature()`; F1 gating via `port::Avail` (docs/SETUP.md, *Version-aware code*).
- SDK translation units (os/gx/vi/pad/dvd/ar/card/ai/dsp/...) are **HLE**'d by name: `HLE(Name) { ... }` in `src/recomp/hle_*.cpp`. Args r3–r10/f1–f8, extra ints at `stackArg(c,n)`, structs by pointer, results in r3 (r3:r4 for 64-bit).
- Cheat-style instruction patches: add `patch <id> <addr> <word> [us] [pal]` to tools/recomp/hooks.txt (the recompiler emits original vs replacement behind runtime switch g_patches[id]) and flip it with setPatch(id, on) from runtime.h. Use this for Action Replay/Gecko `04` code patches instead of case-by-case hooks.
- Any game function can be replaced: add its symbol to `tools/recomp/hooks.txt` + `HLE(symbol)`.
- `src/recomp/ctx.h`: guest memory (`hostp`, `rd32/wr32`, BE), MMIO (0xCC008000 WGP → Aurora FIFO), Ctx/paired singles.
- `src/recomp/sched.*`: one host thread per OSThread, only one runs guest code (priority scheduler); interrupts via `postIrq`/`postIrqAfter`, delivered at loop back-edges/HLE calls or by the idle poster.
- `frame.*`: guest runs only inside an Aurora frame; handoff at `VISetNextFrameBuffer`. VI retrace timer 59.94 Hz; AI DMA interrupt paced by the SDL3 audio device drives JAudio (docs/AUDIO.md); DVD reads have modelled latency (game depends on it).
- Aurora local patches: `patches/aurora/*.patch` (auto-applied at configure). 0002 = vertex arrays with size 0 sized from draw indices. 0005 = post-process hook (`include/aurora/postfx.h`: WGSL pass chain on the game image before ImGui), used by the CRT filter (`src/recomp/crt.cpp`, F1 > Visuals; `LM_CRT=<preset 0-3>[,<scanlines 0-2>]` test override). 0007 = EFB copies to RAM (`lib/gfx/efb_ram.cpp`, `include/aurora/efb_ram.h`; port side `src/recomp/efb_copy.cpp`; docs/RENDERING.md).
- Aurora patch 0008 = color texgen (GX_TG_SRTG) from the lit channel, missing vertex color = white, and Z textures (GXSetZTexture); docs/RENDERING.md (flashlight beam, GBH sub-view clear).
- `src/game/`, `lmport` target: older hand-port prototype + dev viewers (reference only).

## Debugging
- `LM_TRACE=ring` (last 64 calls dumped on fatal) | `LM_TRACE=8000E46C,...` (log entries) | `LM_TRACE=all`
- `LM_WATCH=<addr>[,<len>]` report guest stores (use with LM_TRACE for function names)
- EFB copies (docs/RENDERING.md): `LM_COPY_LOG=1` (every GXCopyTex + textures over copied memory + counters), `LM_FRAME_DUMP=<dir>,<first>,<last>[,<step>]` (native-resolution guest frames as .ppm, deterministic by frame number unlike window captures), `LM_EFB_RAM=0/1`, `LM_EFB_READBACK_ALL=1`.
- `LM_WATCHDOG=1` dump guest threads every 3 s; `LM_TRACE_MQ=1` message-queue log; `LM_DVD_SPEED=1` console-speed disc.
- `LM_IRQ_STALL=1` logs the running guest thread whenever an interrupt waited > 10 ms (add `LM_TRACE=ring` for its recent functions): a guest thread holding the CPU through a long host call stalls everything (docs/RECOMPILER.md). `LM_LOG_TIME=1` prefixes log lines with host ms (timing races).
- GPU cost per pass: `AURORA_GPU_PROFILE=<s>` logs GPU ms per presented frame of every pass/zone, busy time and GPU share (Aurora 0210, no Tracy needed; docs/RENDERING.md "GPU cost"). Lightly loaded GPUs clock down: compare busy/fps at similar load.
- Progress/equipment state for tests (src/recomp/test_state.cpp): `LM_TEST_STATE=poltergust|fire|water|ice` (combine with `+`) keeps Luigi equipped every gameplay frame. `poltergust` gives Poltergust + Game Boy Horror (Luigi +0x792 |= 4|8, the <WEAPON> event bits); `fire`/`water`/`ice` also set Luigi +0x1184 (element 2/3/4) and keep the meter full (+0x1188 = 100). Combine with `LM_START_MAP`/`LM_DEV_WARPS` and `LM_SKIP_TEST=<frame>:pos:x,y,z` (or `LM_TELEPORT=x,y,z,frames`), and press A periodically in `--input` (or `LM_SKIP_CUTSCENES=1 LM_SKIP_AUTO=30`) so dialogue does not stall the run. Scripted `L`/`R` also set the analog trigger values. `LM_NOZZLE_DUMP=1` logs the Poltergust controller state (`[actor0+0x7E4]` +0x310/+0x314 and its 0x50-byte input block from Luigi).
- Element meter (HUD update fn_80045F58 / draw fn_80046120, hooked in src/recomp/luigi_states.cpp): `LM_METER_LOG=1` logs the meter object (+0x10 element, +0x1E fade alpha) and the status block (+0x52 level, +0x58 element) on change; `LM_METER_FORCE=<n>` forces the level. With no element the level is the Poltergust heat used (above 0 only while the vacuum pulls objects) and the fill is drawn with vertex alpha 0, so on hardware it is invisible; a visible grey fill while vacuuming is a port rendering bug.
- Cutscene skip / fast-forward (docs/ENHANCEMENTS.md §4): `LM_SKIP_LOG=1` event-state log + flag snapshots, `LM_FF=1` fast-forward always, `LM_SKIP_AUTO`, `LM_SKIP_TEST`, `LM_INPUT_CLOCK=frames`. Test runs that reach events save the game: set `LM_CARD_DIR`.
- `python tools/recomp/addr2sym.py <addr>...`; `tools/recomp/hle_refs.py` lists SDK functions game code calls.
- F1 menu ID conflicts (two widgets with one ImGui ID: red on hover, unclickable): `LM_MENU_ID_CHECK=1|exit|selftest` sweeps every tab/sub-tab with ImGui's mouse and logs `[menu-id] CONFLICT ... <ID stack path>`; `[menu-id] shot` lines mark each page for screenshots. Same label twice in one tab needs a `##suffix`; label-changing buttons use `###id`. Tree nodes in the menu call `menu::openTreesForCheck()` first.
- Missing/flickering geometry: `LM_DL_TRACE=<file>` logs every GXCallDisplayList per frame with its guest call chain; diff consecutive frames to see whether the game stopped drawing something (then it's game logic, e.g. portal culling: docs/RENDERING.md) or Aurora dropped it.

## Testing guidance
- Test a feature where it naturally belongs: general features (ghost rendering, vacuum, HUD, lighting) in an ordinary mansion room with ordinary ghosts after Luigi has the Poltergust/GBH (LM_TEST_STATE presets), not in boss arenas such as Boolossus (map 11) — use boss maps only for boss-specific work.
- Always test with a scratch APPDATA and LM_CARD_DIR, never the user's real settings/saves.
- Runs with --input (or LM_BACKGROUND=1) never pause on focus loss, so several instances can run at once; use one of them for every automated run.
- Automated runs must not show a window: set LM_OFFSCREEN=1 (moves the window outside every display; it keeps rendering). Start-Process -WindowStyle Hidden / SW_SHOWNOACTIVATE do NOT hide SDL's window, and a truly hidden window pauses the game.

## Gotchas
- Don't write C/C++ with `\n` escapes through bash heredocs/python-in-bash: escapes get mangled. Use the Write/Edit tools.
- Write Python files with `encoding="utf-8"`.
- Timing matters: instantaneous HW completion can break game assumptions (BootScene heap race).

## Next steps (paused 2026-10-07)
- EFB depth copies: the game copies Z16 (`fn_8005D8CC`, 640x480, Luigi's self-shadow map) and Z8 (near `0x8005EA5C`, unused depth blur). The Z16 copy is only read as an IA8 texture by the shadow TEV (`fn_8005DD50`): its depth ramp LUT (256x256 IA8, `fn_8005D560`, A = coarse byte from the clamped s coordinate, I = fine byte from the repeating t) goes through swap table 1 (R=I, G=A) and the depth texture through swap table 2 (R=A, G=I) into a GR16 compare, which is only consistent if the IA8 view of the copy has I = depth bits 23..16 and A = 15..8. That is Aurora's conversion and what EFB copies to RAM encode (docs/RENDERING.md); check this before changing the byte order.
